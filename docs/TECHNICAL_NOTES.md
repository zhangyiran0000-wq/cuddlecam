# 贴贴相机 · CuddleCam：开发与功能记录

Android 双人 / 情侣拍照指导相机，原名 CoupleCAM。参考姿势、双人参考线、语音引导与模型随应用离线提供。

## 2.3.2-beta.1 拍摄与语音修复

- 修复导入视频尚未准备好时切后台、关闭预览或重新打开相机，旧播放回调可能关闭新取景、重新唤起空白取景的问题。过期任务不再改动当前画面或新任务的按钮状态。
- 修复系统语音稍晚就绪时与内置语音重叠播放；切换到系统或浏览器语音前停止旧录音。
- 版本明确标为 Beta，沿用原包名与签名，可覆盖同签名旧版。GitHub Release 保持预发布标记，历史安装包保留。

新增回归测试在修复前复现了旧视频回调破坏新取景、语音重叠；修复后验证迟到的成功/失败回调、重新开拍、三秒倒计时及保存。生命周期测试模拟相机和延迟的视频启动，语音测试模拟播放接口；均不代表实体 Android 手机验证。

## 2.3.1 正式名称

名称确定为「贴贴相机 · CuddleCam」。应用标签、界面、项目名称、安装包及新照片名称统一更新；新照片保存到 `Pictures/CuddleCam`。保留原 Android 包名和签名，可覆盖旧版，原有照片保留。此版本沿用 2.3 的拍摄与检测逻辑。

## 2.3 检测与提示修正

- 实时取景使用连续视频跟踪；找不到第二张脸时，结合近期脸部位置和参考线做局部补检，并分帧尝试倾斜与曝光变换。补检要求位置、大小及重复观测一致，历史位置只用于寻找，不作为当前帧的可见人脸。
- 区分「暂未检测到人脸」和「只确认到一张脸」。连续约 9 秒仍未成功，提示可直接按快门或用三秒倒计时。同一段漏检中每种提示只播报一次；不再循环要求两张脸朝向镜头。
- 单人彩蛋只在未选姿的自由取景中触发。选姿后的双人引导不会因为侧脸、亲吻遮挡而播报单人彩蛋。
- 应用名称改为「贴贴姿势相机」，界面英文名为 CuddlePose Camera；新照片保存到 `Pictures/CuddlePose`。保留原 Android 包名与本地签名，便于覆盖旧版。

完全侧脸、亲吻遮挡和弱光仍会漏检。图像回归使用随包生成式样片，不代表真实用户的识别准确率；实体手机的摄像头、旋转和模型性能仍需实测。不会用推测出的第二张脸触发自动拍照。

## 开发与构建

克隆后先安装 Git LFS 并运行 `git lfs pull`，模型不能只保留 LFS 指针文件。Android 构建需要 JDK 17 及以上、Android SDK 35：

```powershell
git lfs pull
.\gradlew.bat assembleDebug
```

APK 位于 `app/build/outputs/apk/debug/`。仓库不包含开发签名、旧盘对话、恢复备份及本机构建工具；新电脑使用 Gradle 默认调试签名，无法直接覆盖不同签名的旧安装。本机恢复的密钥仍保存在 `.local-signing/`，离线构建可运行 `./build-local.ps1`，输出 `outputs/CuddleCam-2.3.2-beta.1.apk`。

验证逻辑和界面：

```powershell
npm install
npx playwright install chromium
npm test
npm run test:ui
npm run test:features
npm run test:lifecycle
npm run test:detector
npm run test:live-detector
```

Windows 测试优先使用已安装的 Edge，也可设置 `BROWSER_EXECUTABLE`。功能测试中的 VLM 回调和部分人脸输入有明确模拟；两项 detector 测试运行随包的真实 MediaPipe 模型。浏览器测试不替代 Android 真机测试。第三方模型许可证随 `web/vendor/` 保留。

## 2.2 单手操作与本地 AI

以下为 2.2 的历史改动，2.3 延续这些功能。交付安装包使用 `.apk1` 扩展名，手机安装前需改回 `.apk`。

- 菜单无需滚动：拍摄设置分六组，模板库按钮翻页，模板类型以短面板弹出；美颜每次调整一个参数。拍后分「画风 / 人像 / 继续拍」三页，保存按钮固定可见。常用控制靠近快门侧；横竖屏和倒置时重新布局。
- 音量键交给系统，不作为快门，也不强制改变音量通道。屏幕快门保持在检测到的前摄开孔对侧。系统不提供开孔信息时，可指定镜头所在边缘，应用记住后随旋转换算。
- 「AI」页增加「AI 自适应参考线」：本地 SmolVLM 提供场景分类，MediaPipe 双人位置与模板裁切约束决定几何范围。高置信度（至少 0.70）的新场景可缓慢调整留白和参考线大小；两人入镜后最多缩小约 2%，水平调整约 1.2% 画宽。无双人时最多缩小约 6%、水平约 5.5%，并受模板边界约束。可撤销或关闭，手动锁定、倒计时和邀请靠近时不会被 AI 改动。它不生成新姿势、脸或肢体，不改变保存照片的构图。
- 自动场景分析默认开启，可关闭。取景稳定后分析，至少间隔 20 秒，画面不变时不重复调用。每次结果只接受当前模板、当前画面且仍及时的输出；当前适配最多保留 60 秒后逐步退回人脸适配。模型失败时保留原拍照流程。
- 单人彩蛋：持续约 7 秒识别到一个清晰、完整入镜的人脸时，播报「你需要先找一个对象呢」。它依赖人脸检测，不能证明画面中实际只有一个人。看到双人后至少等待 30 秒，每段连续取景最多一次，跨次提醒至少间隔 2 分钟；倒计时、菜单操作、遮挡及明显过暗/过亮时不触发。声音页可关闭「单人彩蛋」，关闭姿势语音或全部静音也会禁用播报。内置 `audio/solo.wav`，不需要联网语音服务。

验证命令：`node tests/behavior.mjs`、`node tests/ui.cjs`、`node tests/features.cjs`。界面测试使用模拟相机；功能联动测试的 VLM 回调使用模拟结果，实际 Android VLM 性能与摄像头仍需真机验证。

Android 10 及以上的双人前置自拍相机。打开后请求相机并显示当前实景，横屏以 16∶9 取景，竖屏以 3∶4 取景。安装包自带 114 张生成式参考照、每个姿势对应的参考线、识别模型和普通话语音片段。

## 浮动构图

选好模板后，参考线会按手机横滚、俯仰做小幅透视调整，双人半身的胸肩始终延伸到取景底边。手机端读取重力方向，缺少重力传感器时使用低通滤波的加速度计。传感器读数不可用时，仅在两张脸的倾斜方向一致时估计横滚。

应用在本机比较画面两侧的纹理、色彩和亮部，避开已识别的人脸与估算的肩部区域。连续三次采样一致后，为风景预留的位置才开始改变。空景偏移量最多占画宽的 12%，两个人入镜后逐步收回到 1.8% 以内。手动调整、靠近动作和倒计时期间保持构图。可在拍摄设置中关闭「浮动构图」，手机开启减少动态效果时默认关闭。参考线只显示在取景中，保存的照片保留原始构图。

两个人一前一后、手机偏向一侧时，还会比较两张脸相对模板的大小比例。连续三次观测取中值，用于微调近侧和远侧的参考线。这是单张平面线稿的透视近似。

## 拍摄

1. 打开相机，轻点屏幕快门拍照。相机根据屏幕开孔和旋转方向把快门放在前摄对侧。系统无法确定开孔时，可点「镜头位置」指定当前前摄所在边缘，应用会记住它在机身上的位置。拍摄设置按标签切换，模板库用上一页和下一页浏览。
2. 对准想保留的风景，取景稳定后自动展示三款情侣模板。各卡用同一帧现场画面预演双人的位置、大小和方向，并标出构图留白。可以只看亲吻、依偎、自然或俏皮，也可以换一组。换过风景后点“新取景 · 更新”重新推荐。模板库支持按分类和动作搜索，并可选择相册背景。
   模板面板里的「色色优先」默认关闭。开启后，托颊轻吻、亲耳前脸颊、回身轻吻等暧昧动作会在当前分类中获得更高的推荐权重。此偏好同时影响推荐卡和模板库的顺序，保存在本机。
3. 点选姿势，按开场的角色标记入位。两张脸稳定入镜后，参考线持续跟随距离变化，连续三次检测取中值，小幅晃动会被忽略。接吻遮挡时保留已有大小，重新看到两张脸后继续跟随。拖动、缩放或关闭“自动跟随”可锁定大小和位置；在拍摄设置里点“自动跟随”即可恢复。取景设置里可切换起形稿、双色稿和漫画。就位后线条淡出，需要调整的头部、肩旁或手的位置局部保留。
   快拍与选好模板后的取景界面都有“美颜”入口。可开关美颜、选轻柔／自然／明显三档，或分别调节磨皮、瘦脸与气色（0–100%）。调节时暂停自动拍摄并实时预览。应用会记住选择；拍完在“人像后期”里还能继续调整。
   语音会分清拿手机的人和另一位。亲额头、轻吻、抵额和碰鼻等动作先提示两人朝向镜头，取得双人尺寸后再播报所选动作。构图就位后会提示靠近，并留出反应时间。此时短暂遮住一张脸仍可自动拍摄。也可以手动拍摄，或使用三秒倒计时。
   快门音效默认关闭。取景角落的扬声器按钮可分别设置快门音效、姿势语音，或全部静音；设置自动记住。随手拍默认只给可视反馈和可选的轻振。引导拍摄开启语音时会播报“拍好了”。可选快门音效和语音跟随安卓的媒体输出。系统按键和返回手势遵循 Android 默认行为，由系统决定音量键调节哪一路声音。Android 13 及以上设备若明确要求系统快门声，面板会显示该状态。
4. 拍完进入「照片漫画化」。可以直接保存原图，或点选动画人像、暖光绘本和黑白线稿。画风默认 100%，可按住看原图或调低强度，最后保存到 Pictures/CuddleCam。模板库的「从相册修照片」也能处理已有照片，导入最长边上限为 2560 像素。

## 2.0 本地 AI 构图

选定情侣模板后，在「拍摄设置」点「AI 看构图」。也可以先从相册选背景、选模板，在姿势预览里试。打开「选姿后自动分析」会记住偏好，在选姿后的取景短暂稳定时尝试一次。模型和中文语音都随应用提供，取景帧只在内存中处理。应用没有网络权限。

SmolVLM-256M-Instruct 的量化视觉编码器和语言解码器由 Android 原生 ONNX Runtime 在后台运行。模型读取一张当前画面，给与人像、林木、街景、水景、山景、室内等相关的候选词打分，再由应用选择对应的简短中文建议。本版限定输出范围。画面过暗、模型不确定、模板已换或画面变化时，会跳过建议。面部朝向、接吻时机和快门仍由原来的实时检测负责。界面里的秒数从原生收到该帧到判断完成，首次包含模型载入，不含语音起播。

对于识别到的街景或自然风景，可以点「试用留景参考线」，在模板已有的头部和肩部边界内小幅缩小参考线，点「撤销」恢复。缩放比例由应用控制，模型只提供场景判断。导出照片沿用 1.17 的动画人像。[模型来源](../web/vendor/coach/NOTICE.txt)

## 推荐与离线后期

114 张参考照包括 6 张单独设计的样片和 12 组、每组 9 张的动作变体。每个候选都有独立参考画面、前景占用图以及两个人物的脸部位置和方向目标。带有可靠手部关键点的互动姿势还会比较手的位置与形状。

每个模板都从起形稿、漫画稿和人物抠图中标定了胸肩可以裁切的范围。推荐图、取景参考线、人脸适配和手动调整共用同一套构图规则，保证画面下沿穿过人物轮廓。检测到的两张脸过远或位置不合适时，拍摄引导会先提示调整手机。更新模板图像后可运行 `python design/calibrate_torso.py` 重算范围。

MediaPipe Image Embedder 使用 MobileNet V3 Small 提取现场背景特征，与各样片分割出的背景区域比较。排序结合留白、人脸附近的背景细节、人物遮住高细节区域的程度和弱光难度。手机在所选模板分类中挑出最多六个候选，把预先分割的人物放在现场画面的建议位置，用 NIMA 比较模拟构图。同等匹配度下，优先展示不同互动类型。换一组会跳过已展示的模板，看到本轮末尾后可以重新浏览。模型暂不可用时，仍依据现场构图和动作差异选出候选。

起形稿和双色稿共享头部朝向、眼线以及肩颈结构。193 个头部取自样片上检测出的脸部网格，另外 35 个侧脸或遮挡头部按对应照片手工标注。肩臂结合原插画笔画与姿态检测，检测到手部时会提取手形。侧脸轻吻和亲额头两款又按照原参考照片用曲线单独绘制。双色稿用暖橙和青蓝区分两人。

“漫画”选项的 114 张透明参考线由 ImageGen 依据各自的参考照绘制，构建时将线稿与对应照片中的人物轮廓配准。其中有 94 款还在原图和插画中匹配到可靠的眼部锚点，用局部变形修正眼位偏差。相机沿笔画采样现场亮度，自动切换浅色与深色墨线。设置可调整线稿浓度。[线稿提示词](../design/guide-prompts.md)

可选的实时美颜通过 WebGL 在取景层处理已定位的人脸，手机不支持实时渲染时仍可拍后应用。拍后在原始取景帧上识别脸部网格。气色局部调整皮肤和唇色，磨皮根据局部明暗差异保留边缘，并避开眼、眉、唇和鼻孔。瘦脸在两侧下颌做平滑局部变形。预览采用缩图，保存时在成片尺寸重新应用参数。

动画人像沿用 1.15 的 Face Portrait v2，以 RGB 输入和 512 像素方框镜像补边绘制整张合照，再裁回原画幅。选择 100% 可重现原版画风，调低强度可保留更多原片细节。暖光绘本使用 DCT-Net 的设计插画预训练权重，根据画面里检测到的人脸大小，按比例把整幅照片缩放到长边 480 至 768 像素，再一次绘制两个人和背景。侧脸遮挡导致人脸检测失败时使用 576 像素。黑白线稿使用 Informative Drawings，以长边 512 像素预测灰度笔触。保存时恢复原画幅和导入尺寸。画风为 100% 且美颜关闭时直接显示模型输出，降低强度可混合原片。模型、推理引擎都随 APK 安装，后期在手机本地运行。生成结果仅缓存在当前照片的编辑会话中。[模型和许可证](../web/vendor/style/NOTICE.txt)

## 工程

用 Android Studio 打开此目录，或使用 JDK 17 以上、Android SDK 35，运行 `gradlew.bat assembleDebug`。相机、系统语音、权限和相册写入由 Android Activity 提供，取景界面和离线推理由本地 WebView 运行。建议使用更新过的 Android System WebView。

测试安装包使用本工程的本地开发签名。请保留 .local-signing 中的开发密钥，以便后续开发版本覆盖安装。

模型与库取自 [Google MediaPipe Tasks](https://github.com/google-ai-edge/mediapipe)。扩展姿势的线稿在构建素材时使用 [Informative Drawings](https://github.com/carolineec/informative-drawings)。内置普通话短句用 [Piper](https://github.com/rhasspy/piper) 的华研模型预先合成。
